# 产品架构定义 — 市中心医院 · 综合运营决策指挥大屏

## 产品定位
面向医院决策层（院长、党委书记、业务副院长、医务/运营管理部主任）的超高清实时综合运营决策大屏（2048 × 1152 分辨率）。

## 技术栈声明
- 框架：Vue 3 (Composition API, `<script setup lang="ts">`)
- 语言：TypeScript
- 样式方案：Tailwind CSS / Scoped CSS + CSS Custom Properties (设计令牌)
- 图表方案：ECharts 5 + 深度定制科技大屏主题
- 构建工具：Vite 5+

## 页面与组件清单
| 组件名称 | 布局区域 | 核心内容 | 渲染模式 |
| :--- | :--- | :--- | :--- |
| `HeaderBanner` | 顶部通栏 | 医院院徽、院训、主标题、国家战略标语、实时时间、运行平稳状态胶囊 | 原生 DOM + CSS 流光特效 |
| `KpiCards` | 左上区域 | 今日门急诊、在院患者、床位使用率、今日手术 4 核心指标与微趋势图 | 原生 DOM + SVG 迷你走势 |
| `DrgDipAnalysis` | 左下区域 | CMI 与盈利能力四象限散点图、四象限业务标签、四类科室图例 | ECharts 四象限散点图 |
| `CampusMap` | 中间主体 | 3.5D 医院园区等轴测三维全景、4 栋楼宇动态交互浮标、指北针、地面导览标 | 高精院区底图 + 原生 DOM 绝对定位浮标 |
| `ValuePillars` | 中间底部 | 患者至上、质量安全、精细运营、高质量发展 4 大战略支柱看板 | 原生 DOM + 矢量图标 |
| `DepartmentRanking` | 右上区域 | 临床科室运营效率 Top 10 排名榜、指标透视、评分进度条 | 原生 DOM 表格 + CSS 渐变进度条 |
| `WarningAlerts` | 右中区域 | 5 项重点运营预警与待办事项、分级标签（紧急/重要/一般）、下发与督办按钮 | 原生 DOM 列表 + 交互操作按钮 |
| `TrendCharts` | 底部通栏 | 门急诊、住院、手术、床位使用率近 7 天历史趋势图（渐变填充面积折线图） | ECharts 4 折线图矩阵 |
