## 已完成的修复

1. **部署与配置**：种子默认关闭且空值不回退；生产口令与证书强约束；HTTP 跳转 HTTPS、Secure Cookie、私有大屏；固定镜像名称；命名卷持久化；修复静态头像文件读取权限。
2. **功能与业务边界**：五项个人偏好实际影响筛选、刷新、声音、金额与姓名；保存失败回滚；会话与业务日期同步；工单分页、接单与办结页面；明确标识演示数据；路由懒加载和图表按需注册；修复尺寸观察循环与侧栏链接语义。
3. **权限与脱敏**：生产端点显式授权，未知角色与新路由默认拒绝；科室工单/人员在 SQL 中过滤且 total 同口径；非管理身份强制脱敏；个人偏好归实际会话；科室页头不请求全院告警；路由和处理器的权限拒绝均记审计。
4. **测试与 CI**：实库不可达直接失败；新增配置、偏好、声音、权限范围、工单闭环与页面巡检；CI 分别运行演示与生产权限模式；升级存在可达漏洞的 Go/JS 依赖，运行环境更新为 Node22、Go1.27、Alpine3.24。
5. **运维与云环境**：可重复的安装/启动脚本；首次演示初始化与正常重启区分；拒绝自动初始化外部数据库；备份 0600、拒绝覆盖，恢复限新库且单事务；完成停库恢复演练；云配置草稿已保存。
