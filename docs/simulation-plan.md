## 1. Mock 数据纪律（L1，当前唯一生效层）

1. **集中**：`src/mock/` 按域分文件（`overview.ts / medical.ts / drg.ts / alerts.ts / departments.ts ...`），页面 `import` 取用
2. **契约对齐**：字段名照 `api-contract.md` snake_case；金额/率值口径照契约 §1.3（聚合万元/明细元；率值展示浮点）；枚举值域照契约附录
3. **自洽**：同一指标在不同页面出现必须同源同值（如门急诊总量在首页/医疗页/大屏一致）；环比方向与数值自洽
4. **像真的**：数字量级与契约示例同源（门急诊月 ~1.0-1.3 万 / 日 ~400-800、在院 ~1,846、床位使用率 85~95%、手术月 ~1,286 / 日 ~45、ALOS 5~9 天）；趋势有星期/季节起伏，不是直线
5. **剧情锚点**（演示讲得出故事）：骨科 DRG 亏损、急诊留观超时、耗材占比超标 —— mock 数据里要能挖出来

## 2. 演示剧本（L1 版）

1. 首页：全院体征一览 → 风险预警区出现"急诊留观超时/骨科耗材超标"
2. 专题分析 DRG 子页：四象限/病组盈亏 → 骨科亏损定位
3. 医疗业务/运营管理：科室明细表 → 脊柱微创组耗材占比异常
4. （P2 后）督办派发 → 工单流转 → 指标复常

## 3. 远期仿真器（未实施，保留要点）

v1.1 的核心设计保留为后端启用后的方案：虚拟时钟 `sim.clock` 单源、SimTick 原子事务、DayGen/Intraday 生成模型（双峰门急诊曲线、星期因子、LogNormal LOS、Poisson 手术）、告警去重键、`POST /sim/reset` 开箱重置。详见 git 历史 v1.1 文档。
