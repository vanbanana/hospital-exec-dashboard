# 统一响应包络与错误码规范 — EDSS

> 版本：v1.1（契约冻结基线，v2.0 改版中**保留未动**，文末附 v2.0 增补注册）
> 状态：后端/接 api 层启用时生效；当前纯 mock 前端阶段为前瞻规范。
> 冻结契约。任何端点必须返回本包络；前端 http 拦截器按本规范统一处理，**业务页面不重复造错误处理**。

## 1. 响应包络（Envelope）

**成功**（HTTP 200）：
```json
{ "code": 0, "message": "ok", "data": { }, "trace_id": "a1b2c3d4e5f6", "ts": 1758153000 }
```

**失败**（HTTP 状态按 §3 映射，包络不变）：
```json
{ "code": 20101, "message": "用户名或密码错误", "data": null, "trace_id": "a1b2c3d4e5f6", "ts": 1758153000 }
```

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| code | int | 业务码。`0`=成功；非 0 见 §4 注册表 |
| message | string | 人类可读（中文）。前端默认直接展示，也可按 code 覆盖文案 |
| data | any / null | 成功负载；失败时可为 null 或含 `fields` 校验明细 |
| trace_id | string | 每请求唯一（middleware 生成），日志排障用；前端报错时随用户反馈上送 |
| ts | int | 服务端 unix 秒 |

**分页负载约定**（data 内嵌）：
```json
{ "list": [...], "page": 1, "size": 20, "total": 137 }
```
查询参数统一 `?page=1&size=20`（size≤100）。

## 2. 错误码段位

| 段位 | 域 | HTTP 映射倾向 |
| :--- | :--- | :--- |
| 0 | 成功 | 200 |
| 1xxxx | 通用/参数/系统 | 400 / 429 / 500 |
| 2xxxx | 认证与权限 | 401 / 403 |
| 3xxxx | 业务（按模块分段，见下） | 200/400/404/409 |
| 4xxxx | 数据管道内部故障（ETL/聚合任务，对 API 表现为上游无数据） | 500/503 |
| 5xxxx | 外部依赖（预留：HIS/ES/MQ） | 502/503 |

业务段内部分配：`31xxx` 大屏与指标 · `32xxx` 下钻与病例 · `33xxx` 告警与督办 · `34xxx` 字典与组织 · `35xxx` 仿真控制 · `36xxx~39xxx` 预留扩展域

**两条铁律**：
1. **HTTP 200 + 非 0 code 全系统仅 31004 一例**（指标口径正常但无数据）；新码评审禁止再引入此模式。**列表端点空集合一律 code=0+空 list**，不得用非 0 码表达"没数据"。
2. 4xxxx = 数据管道内部故障（ETL/聚合任务），35xxx = /sim 仿真控制 API 层错误，二者不重叠。

## 3. 错误码注册表（唯一事实来源；新增只追加不改号）

## 4. 前端统一处理矩阵（axios 响应拦截器实现）

| 条件 | 行为 |
| :--- | :--- |
| HTTP 200 且 code=0 | resolve(data) |
| code=31004 | resolve(null)，页面自渲空态 |
| code=20002 | 进入 refresh 单例队列；成功→重放原请求；失败→登出跳 /login |
| code=20001/20003 | 清 token → /login?redirect=当前路径 |
| code=20004 | push /403 |
| code=10002 | **抛 FormError(fields)** 至调用方表单（不弹全局消息）；非表单场景落"其余"行 |
| code=20104 | 登录页提示 + 15min 倒计时展示（不解锁接口，运维走 Redis DEL） |
| code=20005/33002/33104 等冲突 | ElMessage.warning(message)，并触发对应 store 的局部刷新 |
| code=10005 | ElMessage.warning，调用按钮置冷却 |
| 其余非 0 | ElMessage.error(message)，console 附 trace_id |
| HTTP 5xx / 网络断 | ElMessage.error('网络异常')，大屏进入"断线重试"态（顶部红条+自动重连倒计时） |

**文案铁律**：message 默认直接展示；仅登录错误（20101）与权限类允许前端自定义文案。禁止前端按 message 字符串做逻辑判断——判断一律按 code。

## 5. 校验错误负载（code=10002）

```json
{ "code": 10002, "message": "参数校验失败",
  "data": { "fields": { "deadline": "必须晚于当前时间", "assignee_id": "不能为空" } } }
```
表单页将 `fields` 逐项映射到 el-form-item error。
