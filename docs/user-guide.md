# 使用指南

启动与账号见 [README](../README.md)。推荐桌面浏览器体验工作台，大屏提供等比适配与填满模式。

## 登录与权限

侧栏按真实账号授权展示。无授权页时显示访问说明，会话过期转登录。头像菜单可退出；演示管理身份可切换展示视角，实际会话权限和个人偏好仍属于登录账号。验证科室权限请退出后登录科室账号。

## 查看指标

首页包含 KPI、趋势、科室排行、关键指标、工作进展、预警、通知和待办。业务页提供不同域的图表和表格，只使用页面实际提供的筛选。科研、患者、质量、资产采用固定统计口径。

一起阅读数据来源、业务日期、统计窗口和金额单位；不同范围的指标不能直接比较。API 失败显示错误面板，可点击重试；保留旧数据时标识 stale，空表与请求失败分别展示。没有自动编造的替代业务数据。

顶栏搜索禁用；系统没有全文检索、通用报表导出、五级病历穿透或医院数据同步。系统设置中的数据源与用户表为登记展示，不提供新增医院数据源或用户操作。

## 预警与督办

1. 在首页风险预警区选择有权限操作的记录，按当前状态认领、派发或关闭。
2. 派发时选择承办人并填写任务要求、截止条件；校验失败时按提示修正。
3. 打开“督办工单”，按状态筛选，用上一页/下一页浏览授权范围内记录。
4. 待接单显示“接单”，办理中显示“办结”；填写非空办结结果后提交。
5. 成功后查看新状态。重复、冲突与越权操作返回错误，不能强行完成。

操作与审计持久化到数据库。办结处理关联告警状态，不自动重算经营指标。工单查询可能维护逾期状态，并非数据库完全只读操作。

## 个人偏好

修改自动保存，无需提交按钮。成功显示“已保存”；失败提示并恢复已确认值。偏好归当前真实登录账号，重新登录可继续读取。

| 项目 | 实际作用 |
| --- | --- |
| 默认统计范围 | 支持范围选择的页面初始化使用，固定口径页不受影响 |
| 工作台刷新间隔 | 工作台轮询，离开清理；不控制大屏刷新 |
| 预警声音 | 新高风险预警提示；需先点击页面解锁浏览器播放 |
| 金额缩写 | KPI 与指标条展示，不改变存储值或所有表格 |
| 姓名脱敏 | 工单和人员展示；非管理身份服务端始终强制脱敏 |

## 工作台与大屏

有院级入口授权时顶栏显示“数据大屏”。从工作台进入后，“返回工作台”保留进入前的本地地址与查询参数；直接进入大屏时返回工作台首页，再由真实权限导航。

适配按钮切换等比和填满模式，填满可能产生非等比拉伸。浏览器全屏也可用 Esc 退出；返回工作台会尝试退出全屏。快照失败时返回入口仍可用。

大屏定期拉取快照，失败可重试，不保证持续在线。关闭公开大屏时必须有合法会话和院级范围授权。页面时钟是业务仿真时间，不保证医院数据实时更新。

## 设置与数据保存

规则支持启停，不提供任意阈值编辑。仿真控制面只有 API，要求 admin 且启用 SIM，没有网页入口。推进时钟不会启动实时业务生成或重算所有快照。

普通停服与重启保留 PostgreSQL 命名卷。删除卷、重播种或数据库恢复会改变数据；共享前配置 HTTPS、轮换演示口令并吊销旧会话。部署和备份恢复见 [部署手册](production-deploy.md)。
